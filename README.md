The funniest one line a talking elevator could say, 120 characters at most — written in the elevator's own voice for make.fun's "What the Elevator Would Say" bounty.

> "You pressed the close button seventeen times. I heard you the first sixteen."

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
